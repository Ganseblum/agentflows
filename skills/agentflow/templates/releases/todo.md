# 发布队列 — <版本或批次>

> 本文件是 releases/ 侧的**唯一**载体：一张表同时回答「这个批次还欠什么、验过什么、发布动作是什么」。
> 状态列**只允许写引用**（指向 plan 任务行 / run 的 decision / ISS 编号），不允许写「进行中 / 已完成」
> 这类形容词——批次状态唯一权威在计划看板，验收事实唯一权威在 run 记录。本仓没有真实发布流程
> （无远端 / 无部署配置）时，Init 不创建 releases/ 目录；已创建而无发布动作的，本文件写
> 「无发布动作 + 理由」或经用户确认后删除，不要为了填表发明发布动作。
