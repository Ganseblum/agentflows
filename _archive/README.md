# _archive — 冻结历史（只读）

本目录存放只读的冻结历史。约定如下（与 `skills/agentflow/references/contracts.md` 的冻结归档条款一致）。

## 三级冻结

- **L1 只登记**：在 `index.md` 登记一行（日期 + 说明），文件原地保留；
- **L2 就地冻结**（日常默认）：文件头加一行冻结声明（冻结日期、被谁承接、承接位置）+ 索引登记，不搬家；
- **L3 整树进归档桶**：`_archive/<类型>-<年月>/`，桶内放只读声明（命名、写入者、冻结原因）。

## 两条判据（满足其一才冻）

1. 读者可能把历史当现行真源；2. 有不再生效但需要被解释的约定。两条都不满足则不冻——git 本身就是完整历史。

## 四步（L3）

先迁活跃落点 → 未决项出表（转 `issues/` 或批次，索引保留「冻结原文」指针）→ 登记 → 只读化。

## 反例

在途件不得冻结；不得按时间冻结；单份文档不搬家式冻结（引用会断）。

## 冻结原文的引用

桶内原文保留历史引用、不改写（与 `CHANGELOG.md` 同款登记）。
