## 类模式

Agentflow 会话向用户交付独立书面产物（数据分析报告、状态汇报、交付说明）时，表达纪律的四个装置——document-chain.md 条款、模板写前提醒、doc_chain.py 机器检查、reviewer 文档模式——全部不适用：它们全部锚定文档链形态。产物里的黑话有两族是文档链条款未点名的新形态：**(b) 代号一次定义后裸用作正文持续主语**（口径表/图例定义过，正文全程裸用，读者须回翻或记忆映射）；**(c) 数据库模式词直搬散文主语**（可解析标识符非发明行话，字面不受现行条款约束）。

首现语料：aiwork 仓 temp/ 两份会话内交付的分析报告（2026-09-16/17，用户 2026-09-22 九组词反馈，见 ISS-2026-040 现象节引文）。

## 归纳内容（已吸收进 Agentflow 的哪一层）

已归纳于 Agentflow 0.8.6（candidate 0.8.6，`releases/0.8.6.json`——已随 2026-10-12 版本记录停用删除、git 历史可回溯，human-gated 用户批准）：`document-chain.md` 表达纪律条款增两条形态规则（**代号裸用**——代号只在定义处，正文白话主词+「白话（代号）」成对伴随，判据=不回翻定义表能读懂任意一段正文；**模式词分域**——标识符留代码/SQL/日志语境，散文用业务白话，判据采用户规则原文「正文用『执行』，代码和 SQL 里保留 Run」）+ 作用域声明（纪律同等适用于会话交付物）；`roles.md` supervisor 增交付前写前自查职责；`reviewer.md` 增两个可逐条引用检查项+会话交付物指派评审路径；`doc_chain.py` 新增 **C14 代号裸用**（单大写字母+桶，排除定义表/代码/成对形式）与 **--file 单文件模式**（C12/C13/C14 文本形态检查，跳过 C1-C11）作为可达装置；自测 26→38 case。C15 模式词分域机器检查经真语料评估误报面不可控（状态→视觉图例类与真缺陷行级不可分），降级为条款文本+reviewer 管辖（证据=自测 case 34）。同批已按用户对照表就地修复两份存量报告（ISS-2026-040 现象节语料），修复后 --file exit 0。measurement: none（method-level change，预防效果待首个真实交付物对照，regression_status=not-run）。
