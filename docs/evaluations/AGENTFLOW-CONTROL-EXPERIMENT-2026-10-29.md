# 同题对照实验：with / without Agentflow（2026-10-29）

> 来源：`docs/PENDING-DECISIONS.md` 第 16 条 A（2026-10-29 用户拍板「补一次同题对照实验」），
> 由 `docs/features/feature-2026-10-29-全面修正与瘦身/plan/PLAN-FIX-001.md` T24 承接。
> 目的：在同一个真实小任务上，比较「按 Agentflow 方法执行」与「普通执行」的成本与结果，
> 给「不用 Agentflow 需要多少成本」补一组实测数字。**这不是统计显著的评测**，只是一次可复现的对照。

## 1. 协议

- 任务：给一个小型 Python CLI（`sales.py`）增加 `--top N` 选项——按区域总额降序取前 N，同额按
  区域名升序；无 `--top` 时行为不变；`N < 1` 与非法 `amount` 均以退出码 2 报错；补回归测试。
- 两组的代码、测试与 `TASK.md` 完全相同；各自在一次性目录中独立完成，互不可见：
  - **without**：只给任务，按平常方式实现。
  - **with**：额外要求按 Agentflow 方法执行——读 `skills/agentflow/SKILL.md` 与
    `skills/agentflow/references/execution.md`，写最小计划、测试先行、记录原始证据、最小改动；
    完成后由一名独立 reviewer 评审，评审要求改动时做一轮聚焦修复并复审。
- 判定：两组完成后由同一份隐藏验收测试（4 例）判定正确性；该测试不在任何一组的工作目录内。
- 执行环境：本机、同一宿主、同一模型族；模型标签不可得，记 `unknown`。
- 代理指标：墙钟时间、测试运行次数、失败/返工轮次、隐藏测试通过数、diff 体量。
  **没有人类参与，因此没有人时数据**；墙钟与轮次是代理指标，不能换算成人效或成本结论。

## 2. 数字

## 3. 观察到的事实

1. **正确性没有差异**：两组都通过 4 例隐藏验收测试；这一题不足以让两组的产物在行为上分开。
2. **方法有可测成本**：实现阶段 203 秒对 49 秒（约 4.1 倍）；加上评审与修复约 632 秒（约 12.9 倍）。
   成本主要来自计划、证据留档与独立评审，而不是实现本身。
3. **方法抓到一处真实的测试质量缺陷**：评审 P1 指出 with 组的 `--top` fixture 区域名序与总额序
   恰好重合，「无 --top 时行为不变」断言没有判别力——默认分支若被误改，测试仍会全绿。该问题在
   without 组同样存在（其 fixture 也用了名序与总额序相近的区域名），但普通执行没有评审环节，
   因此没有被发现。这是本次实验中方法唯一可归因的增量价值。
4. **测试先行本身没有减少返工**：with 组的「预期红→绿」是流程要求的 1 轮，不是意外返工；两组
   实现阶段都没有出现实现失败后的二次修复。

## 4. 不能从这个实验得出的结论

- 不能得出「Agentflow 更便宜或更贵」的普遍结论：n=1、任务小、无人类参与、模型标签不可得。
- 不能把墙钟换算成人时：两组的「执行者」都是 AI 代理，人类的阅读、审批与等待时间未测量。
- 不能把「抓到 1 条测试质量缺陷」外推为缺陷逃逸率下降：没有基线逃逸率，也没有重复运行。
- 不能把隐藏测试通过当作「方法有效」：两组都通过，说明这题对方法不敏感。

## 5. 结论与后续

- 本次对照的证据支持一个保守结论：**在小而明确的任务上，Agentflow 的成本明显更高，正确性收益
  未体现；它在本例中的可归因价值是评审抓到了一处无判别力的测试。**
- 要把「成本 / 收益」变成可决策的证据，需要：同一题重复 ≥3 次、至少 3 类任务（小修、跨层、
  缺陷诊断）、记录人类审批时间，并用「隐藏测试 + 评审发现中的真实缺陷」双指标。
- 在此之前，对外叙事不得声称「Agentflow 成本更低」；本报告即是该口径的实测依据。
