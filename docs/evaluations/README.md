# 评测交付件（evaluations）

本目录收存对本仓做整体评测后产出的**交付件**（评测 prompt、评测报告、据评测报告生成的行动件）。
它们是「某一时刻对仓库的只读快照式判断」，不是持续维护的活文档：报告里的分数、行号与结论
**以报告基线 revision 为准**（每份报告头部标注了被评测的 commit），随仓库演进会自然过时，
不随源面回改（勘误以报告自带勘误节为准）。

历史上这些文件落在仓库根目录；2026-10-20 起统一收进本目录（用户拍板：根目录只留入口类文档，
记录性内容入 `docs/`）。

## 与记录面的关系

- 本目录是**评测档案**，不是现行记录根（`docs/issues/`、`docs/features/`、`episodes/`、
  `docs/releases/`、`reviews/`）；评测发现的缺口按修复批次落到现行记录根，不在此立项。
- 报告按当时事实写作，正文含已退役路径时以引文（围栏/内联代码）或勘误说明呈现，不回改。
