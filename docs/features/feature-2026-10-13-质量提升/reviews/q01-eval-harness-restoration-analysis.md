# Q-01 评测装置恢复分析

> 状态：待用户拍板。关联：`docs/PENDING-DECISIONS.md` 第 8 条①；`proposal/prd.md` Q-01。

## 一、现状

- 评测装置（`evals/`、`eval_runner.py`、`host_adapter.py`、`policy.py`、`seed_grader.py`、
  三个 schema）已于 2026-10-12 整线裁撤。
- 设计知识保留在 `docs/design-decisions.md` §3「评测装置：已裁撤，留存的设计知识」。
- 当前状态：**受治理的人工闭环**，不是已闭合的自动学习系统。没有任何实测数据。
- G1 目标（效果可测）需要 A/B 实验，但当前没有测量路径。

**口径更正（2026-10-19 核查）**：本批 spec 里已经定义了替代物——M-F 实验 harness
（`tools/lab/experiment.py`，`spec/be/backend.md` §5）。但该文件**不存在**，代码是被刻意留白的：
`spec/be/backend.md` §3 的 Q-01 行写明「未决前，M-F 只交付判据、接口与记录格式，不写执行代码」。
所以真正的问题不是「恢复一个被删掉的装置」，而是「要不要实现 M-F 并把 Q-01/Q-03 关掉」——
选项 A 的成本因此比"重建"低（判据、字段契约、错误语义已在 §6/§7 写好），但门变更的性质不变。

## 二、问题

G1 是质量批的核心目标之一：在冻结的任务集上完成一次 A/B 实验（装插件一臂，裸宿主一臂），
按事先写定的判据给出结论。但评测装置已删除，无法执行 G1。

## 三、选项

### 选项 A：恢复最小评测装置

按 `docs/design-decisions.md` §3 的设计知识重建评测器。需要：
- 恢复 `eval_runner.py`、`host_adapter.py`、`policy.py`（或重写）
- 恢复 `evals/` 目录与 schema
- 修改受保护的门（`protected-paths.txt`、`tools/lab/validate.py`）
- 冻结任务集与判据

**收益**：可做 G1 实验，获取实测数据，验证 agentflow 的效果。
**风险**：需改受保护门（需独立评审）；需重建评测器（工作量不确定）；宿主可能不支持无人值守调用。

### 选项 B：不恢复，改用其它方式

不恢复评测装置，改用其它方式验证效果。可能的方式：
- 人工 A/B（手动装插件 vs 裸宿主，人工对比）
- 只做 G2-G4（门禁可信、运行态同步、文档可核），跳过 G1
- 用 G5（角色行为可测）作为效果代理指标

**收益**：不改受保护门；不重建评测器；无额外花费。
**风险**：无法做 G1 实验；无实测数据；G1 是质量批的核心目标之一，跳过会影响批次的完整性。

### 选项 D：预注册判据 + 小样本人工 A/B，直接产出「无定论」

prd §1.2 写明 G1 的三种结论都合法：**「有提升」「无提升」「无定论」，但必须附原始数据与判据**。
这条把选项集合从「0 次运行 / 60 次运行」的二选一打开了：先冻结判据与任务集，用几次到十几次
人工 A/B（真实用户任务，不是合成题）跑一遍，按预注册判据给出结论；样本不足时结论就写「无定论」，
并附原始数据与"差多少才够判"的说明。

- **收益**：不改受保护门、不实现 M-F、不需要 Q-03 的 60 次预算；G1 得到一个可交付、可审计的结论
  （哪怕是无定论），比"跳过"更接近批次目标；代价是统计力低，不能声称"有提升"。
- **风险**：人工 A/B 的对照容易被操作者预期污染，必须在跑之前把判据、任务集与样本量写死；
  「无定论」容易被读成"没做"，需要连同原始数据一起交付。

## 四、建议

- **先走 D**：冻结判据与任务集，跑小样本人工 A/B，把「无定论」连同原始数据交付。它不改门、不花钱，
  且是唯一能在本批内闭合 G1 动作的路径。
- 只有当你需要「有提升 / 无提升」这个更强的判定时，才走 A（实现 M-F + 关 Q-01/Q-03）；A 的门变更
  与独立评审不可省。
- B 是兜底：如果连小样本都不打算跑，就在台账里把 G1 记为「本期不测」，别记成"已跳过"。
- 无论选哪个，都需要用户书面确认并记日期。

## 五、决策点

| 决策点 | 选项 | 影响 |
| --- | --- | --- |
| 是否恢复评测装置 | 实现 M-F / 不实现 | G1 能否执行、是否改受保护门 |
| 若实现 M-F | 按 §6/§7 已写好的契约实现 / 重写 | 工作量、时间 |
| 若延后 | 小样本人工 A/B 出「无定论」（D）/ 记为本期不测 | 批次完整性、证据强度 |
