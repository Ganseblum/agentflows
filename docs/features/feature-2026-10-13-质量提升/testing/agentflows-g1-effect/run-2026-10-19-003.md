- **功能结果等价**：两臂 `apply_discount(100,10)` 均为 `90.0`；`round_half_up` 在 2.675 / 2.674 / 1.005

  包级导出），B 扩到 6（无折扣、四舍五入、负数）。两者都覆盖了任务要求的最小面。
- **证据纪律差异（本轮唯一可判的差别）**：A 的报告带 `Ran 9 tests in 0.001s / OK (EXIT=0)` 与
  `unverified:` 清单（浮点异常输入、非本机 Python 版本），B 的报告以「全部 OK」收尾，要我方自行复跑
  才能确认。这正是 S5 要测的东西，不是能力差异。

  费用只能读宿主账单。失败率 0/2（两臂都完成了任务，没有崩溃或超时）。
