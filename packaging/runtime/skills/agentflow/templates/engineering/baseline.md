### UI、文案与可访问性基线

- 多站点 / 多应用：规则按站点分册，不跨站套用；跨站只按白名单复用基础设施，不跨站 import 页面或业务源码。
- 文案与国际化：`<基准语言>`；有 i18n 时新增或修改文案按语言成对落键，不单补一种语言，不在组件里硬编码 UI 文案。
- 可访问性：键盘可完成主路径、焦点可见且弹层关闭后恢复、可操作元素有可访问名称、颜色不作为唯一状态提示；具体标准 `<填>`。
- 格式与命名：格式交给 `<formatter / linter>`；不按个人偏好批量改写存量命名或格式。
