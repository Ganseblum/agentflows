# host — 宿主级全局规则模板

> 用途：把跨仓库的 Agentflow 纪律写进宿主自己的全局指令文件，让它在每个会话默认在场。
> **协议唯一权威是 [`../../references/hosts.md`](../../references/hosts.md)**；本文件只是操作清单，冲突时以该文档为准。

| 文件 | 用法 |
| --- | --- |
| [global-rules.md](global-rules.md) | 托管块正文。整块复制进目标文件，只把 `{{version}}` 换成当前插件版本；不逐句改写 |

## 安装清单（每次都由用户明确确认）

1. **确认目标**：按 `references/hosts.md` 的宿主矩阵确定全局指令文件。矩阵里标"未观察/未验证"的宿主，先做加载实验，确认文件确实会被加载。
2. **dry-run**：打印目标文件的 `realpath`、完整托管块、块外是否会变动；目标若是 symlink，单独列出真实落点。确认后才写。
3. **备份**：任何会改变文件内容的写入之前都要备份（首次追加与后续版本替换都算），备份名 `<文件名>.agentflow-backup-<YYYYMMDD-HHMMSS>`，落在 `realpath` 旁且是普通文件（用 `cp -L` 之类解引用 symlink）。备份只服务第 6 条的前两项校验，两项通过后即删除；整体因加载复述记 `blocked` 时保留到完成为止。
4. **只改块内**：把 `<!-- agentflow:begin vX.Y.Z -->` 到 `<!-- agentflow:end -->` 之间的内容替换为模板正文（`{{version}}` 替换为当前版本）；块外内容一字不动。没有块时追加到文件末尾，追加前确保文件以换行结尾（若原本没有，这是唯一允许的块外改动，须在 dry-run 里列出）。
5. **幂等与拒绝**：块存在且版本相同则不写；版本不同只替换块；标记不完整就拒绝写入并报告，不猜。
6. **三项校验 + 加载验证**：块外内容与备份一致、块内容与模板一致、宿主在新会话里逐字复述块内首行 `## Agentflow 全局规则（托管块，勿手改）`。三项都要保留原始输出；加载拿不到复述就记 `blocked`，不算接入完成。
7. **权限降级**：宿主拒绝写工作区外文件时，按 [`references/hosts.md`](../../references/hosts.md) 托管块协议第 7 条执行（把完整块打印给用户自行粘贴）；差异点只有一处——三项校验改由用户侧完成：前两项（块外与备份一致、块内容与模板一致）由用户运行并带回原始输出，第三项（新会话复述首行）仍逐字执行。
8. **留痕**：在插件仓会话里把观察结果写进 `docs/host-platform-facts.md`；在目标仓会话里不写插件仓记录，把宿主的逐字回复带回插件仓落盘。交接前该宿主行保持"未验证"。

## 各宿主形态

| 宿主 | 写入形态 |
| --- | --- |
| ZCode | 纯 Markdown 块，追加到 `~/.zcode/AGENTS.md` |
| Codex | 纯 Markdown 块，追加到 `~/.codex/AGENTS.md`（加载行为待验证） |
| Claude Code | 纯 Markdown 块，追加到 `~/.claude/CLAUDE.md`（加载行为待验证） |
| Cursor | 项目级候选 `.cursor/rules/*.mdc`，需要 frontmatter；全局位置未验证。实验通过前不提供适配器 |
| 其它 | 该宿主的指令文件；确认不了路径或加载行为就不写 |

## 不要放进全局模板

- 具体构建/测试命令、文档落点、批次目录形态——这些属于目标仓的「Agentflow 接入约定」。
- 某个仓的分支名实例、绝对路径、某台机器的服务地址。
- 需要机器校验的规则——全局文件没有校验器；能机械判定的东西放进门工具，不靠一句散文。
