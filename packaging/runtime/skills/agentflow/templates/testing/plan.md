**三层断言（api 级用例必填）**：协议层（状态码、响应结构）· 业务层（业务字段的值）· 副作用层
（落库、消息、调用下游）。没有数据副作用的用例，要写一条显式的反向断言（确认什么都没变），
不要留空。

**预期必须有契约依据**：预期结果应引用已冻结的 spec、协议或用户确认结论；缺少权威依据时，把该字段列为未定并阻塞相关用例。真实响应属于执行阶段的实际结果，不能用它替代预期，也不能把实现错误固化成期望。
非 HTTP 的调用不许伪造 `method` / `path` 字段；没有骨架标记为「待实现」，不许把不存在写成已有。
