### 2.1 视觉来源（先查再写，禁凭空）
> 这一节回答「我们到底用什么」：组件库、主题机制、token 从哪来。**事实靠查，不靠问**——
> 组件库版本、主题注册点、token 文件路径都能在仓库里找到，查到就写 `path:line`；查不到才挂 V。
> 选哪一种基线是产品/技术偏好，才交给 owner 决策。

| 档位 | 什么时候用 | 要求 |
| --- | --- | --- |
| A 复用本仓既有基线 | 默认。目标仓已有 UI 体系（antd/自研 token/design token 文件/设计规范页） | 来源表逐项写 `path:line` 或链接；不新增第二套体系 |
| B 跨项目移植 | 本仓没有、但组织内另一仓/另一站点已有合格基线 | 写明取自哪个仓、哪个文件/页面；差异项逐条列出（不整包搬） |
| C 冷启动（无任何可参照的项目） | 只在确实没有既有 UI 时 | 先选定一套（优先目标仓技术栈自带的 UI 库默认主题），声明「本批建立基线 v1」，写进 design/ui 变更记录；后续批次按 A 复用，不再重选 |
