# <feature> — 待确认问题台账（spec/checklist.md）

一个问题一行，编号用 `Q-01`、`Q-02`，存量编号原样保留。通过当前会话的提问入口逐轮确认，每轮最多两个问题，每题最多三个选项并说明推荐理由。收到明确答复后填写回答人、时间及原文。

状态取「未确认」「已确认」「已关闭」。阻塞阶段写实际受影响的阶段，非阻塞写「无」。同一问题的状态和答复在此维护，提案、规格和计划引用编号。阶段冻结前关闭本阶段的阻塞项。
