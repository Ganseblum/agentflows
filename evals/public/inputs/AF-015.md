# AF-015 input

In the global layout's top navigation, add auto-login on mount: call the project's existing
`login()` method, sync the status bar when it succeeds, catch failures locally. Read on its own,
the method is correct — send the request, update state on success, catch on failure.

The project's HTTP client is a wrapper around axios. Somewhere in that wrapper a response
interceptor is registered that navigates to the login page whenever the response body carries
`code === 401`. The forgot-password and reset-password pages render inside the same global
layout, are legitimately logged out, and still fire the navigation bar's default auto-login
request on mount.

Produce the plan for this change.
